课程数字人浏览器访问设置说明

课程网站：http://111.63.183.17:9001/

一、已经连接校园网，但数字人仍显示连接失败
1. 新开浏览器标签页，在地址栏输入 http://222.30.145.22:8010/embed.js ，按回车。
2. 如果页面打不开或长时间转圈：确认电脑连接校园网，或校园 VPN 已正常接入。检查本机代理和防火墙；仍打不开时联系校园网络管理员，提供地址 222.30.145.22:8010 和失败截图。
3. 如果能显示 JavaScript 代码，使用 Microsoft Edge 时：在地址栏输入 edge://flags/#local-network-access-check 并按回车。找到“Local Network Access Checks”（本地网络访问检查），选择 Enabled，即显示权限警告/提示的选项；不要选择直接阻止请求的选项。点击 Relaunch（重启）按钮。
4. Edge 重启后，点击右上角“…” →“设置”→“隐私、搜索和服务”→“网站权限”→“所有权限”→“本地网络访问”，打开“访问前询问”开关。回到 http://111.63.183.17:9001/ 刷新课程页面；如果弹出本地网络访问请求，点击“允许”。
5. 如果找不到上述设置：先更新 Edge。仍无法解决时按 F12 打开开发者工具，在“控制台”或“网络”中检查 222.30.145.22:8010 的请求，把报错截图交给管理员。Chrome 的菜单可能不同，请以浏览器实际显示为准。
6. 地址能打开但课程仍连接超时，可能是数字人服务故障；请将课程页面的控制台报错交给管理员。

二、不知道如何开启麦克风，或没有出现授权弹窗
1. 在 http://111.63.183.17:9001/ 点击地址栏左侧的网站图标，打开“网站设置”，将“麦克风”改为“允许”，然后刷新。
2. 如果浏览器提示 HTTP 页面不能使用麦克风：Chrome 地址栏输入 chrome://flags/#unsafely-treat-insecure-origin-as-secure；Edge 输入 edge://flags/#unsafely-treat-insecure-origin-as-secure ，按回车。
3. 在设置项的文本框准确输入 http://111.63.183.17:9001 （不加页面路径，保留端口 9001），将选项改为 Enabled，点击 Relaunch 重启浏览器。
4. 重新打开课程页面，麦克风申请弹窗出现时点击“允许”。没有弹窗时，再检查地址栏左侧的网站设置，确保“麦克风”为“允许”。
5. 仍无法录音：打开 Windows“设置 → 隐私和安全性 → 麦克风”，开启“麦克风访问”和“允许桌面应用访问麦克风”；确认麦克风设备已连接、没有被静音。

注意：网页无法代替用户修改浏览器权限。浏览器版本不同，菜单文字可能略有差别。仅对可信课程网站启用上述 HTTP 例外设置。
