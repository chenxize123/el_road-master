## 二、大模型及服务简介

我单位拟通过“智学路大模型智慧助教系统”提供面向教育教学场景的生成式人工智能辅助服务，服务对象主要为教师、学生及教学管理人员。系统应用于课程学习答疑、教学资源建设、课堂互动、实验反馈和教学评价等场景。

系统主要功能包括：

1. **学习答疑：** 为学生提供课程学习问题的文字问答和连续对话服务。
2. **辅助题目建设：** 根据课程知识点辅助生成填空题、判断题、单选题、多选题和简答题，供教师用于题库建设和教学测评。
3. **实验分析：** 对学生实验提交内容进行分析，为教师了解实验表现和学生遇到的问题提供参考。
4. **讨论分析与总结：** 对班级讨论内容进行分析或总结，辅助教师了解讨论观点和学习参与情况。
5. **课程研究辅助：** 围绕课程研究主题提供文献搜索及课题研究辅助。

本服务的生成内容主要为文字，包括问答回复、题目内容、分析意见、讨论总结及研究辅助内容。课程视频播放等教学资源功能不作为本函所述生成式人工智能生成内容。
