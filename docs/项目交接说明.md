# 项目交接说明

## 项目结构

| 目录/文件 | 用途 |
| --- | --- |
| `src/views/` | 路由页面入口；页面数据和布局主要在这里 |
| `src/components/` | 可复用组件和页面功能模块；`course/`、`class/` 分别承载课程与班级控制台模块，`admin/` 是管理组件，`common/` 是通用组件 |
| `src/api/` | 后端接口封装；`index.js` 是基础请求层，其余文件按用户、课程、班级、考试、实验等功能拆分 |
| `src/store/` | Pinia 用户和权限状态 |
| `src/router/` | Vue Router 路由表和守卫相关代码 |
| `src/composables/` | 可复用页面逻辑，如课程视频、班级详情数据 |
| `src/utils/` | 导入、统计、推荐、权限等工具函数 |
| `src/assets/`、`public/` | 图片等打包资源、静态文件；`public/` 当前含教程视频和批量导入示例表 |
| `src/styles/` | 全局样式 |
| `src/dayi-fronted/` | 独立的 AI 答疑 Vue/Vite 子项目，有单独依赖和打包流程 |
| `tests/` | Node 测试文件；根 `package.json` 暂未配置 `test` 脚本 |
| `docs/` | 项目文档 |
| `dist/` | 主项目前端构建产物，由 Vite 生成 |

| 页面路径 | 页面文件 | 功能/备注 |
| --- | --- | --- |
| `/` | `src/views/Home.vue` | 首页，含登录弹窗入口 |
| `/student` | `src/views/student/StudentHome.vue` | 学生首页 |
| `/resource-recommendation` | `src/views/student/ResourceRecommendation.vue` | 学习资源推荐 |

课程页的模块由 `src/components/course/CourseTabs.vue` 和 `src/views/course/CourseDetail.vue` 组合：基本信息、课程视频、知识图谱、教案、题库、试卷。课程管理与考试模块的插槽虽在 `CourseDetail.vue` 中，但 `CourseTabs.vue` 中没有对应可见标签。

班级页的模块由 `src/components/class/ClassTabs.vue` 和 `src/views/class/ClassDetail.vue` 组合：基本信息、学生管理、知识图谱、课程视频、考试、实验、课题、讨论区。具体模块位于 `src/components/class/modules/`；学生管理仅对教师/管理员显示。

## 新增功能或页面的开发流程

1. **先确定入口位置**：完整、独立的业务页面放在 `src/views/<业务>/` 并注册为路由；课程或班级控制台中的功能优先做成模块，放入对应的 `src/components/course/modules/` 或 `src/components/class/modules/`，不要另造重复入口。
2. **接入路由或控制台标签**：独立页在 `src/router/index.js` 增加懒加载路由、页面标题和角色元数据；课程页同步检查 `CourseTabs.vue` 与 `CourseDetail.vue` 的标签和具名插槽，班级页同步检查 `ClassTabs.vue` 的 `defaultTabs` 和 `ClassDetail.vue` 的具名插槽。现有详情页会从 `?tab=` 读取初始标签，可沿用此方式链接到指定模块。
3. **实现界面与组件边界**：页面负责组织数据和功能模块；可复用区块放在 `src/components/`，通过 props 接收数据、通过 emits 通知页面操作。优先沿用 Vue 3 `<script setup>` 和 Ant Design Vue 的现有写法。
4. **接入接口和状态**：新接口按业务放入 `src/api/<业务>.js`，复用 `src/api/index.js` 的请求层；跨页面共享的数据再放入 Pinia `src/store/`，只在当前页面使用的状态留在页面或模块内。新增环境配置时同步更新 `.env.example`，文档和提交内容不要包含密钥。
5. **补齐访问控制和数据保存**：同时核对路由角色元数据、页面操作按钮的可见性、后端权限与错误反馈。当前全局路由守卫的实际限制尚未接通，不能只靠 `meta` 声明权限。涉及新增、修改、删除时确认接口调用和保存时机符合业务约定，例如题目生成后直接入库。
6. **验证并更新文档**：使用本说明“接手检查”中的测试命令运行测试，再执行 `npm run build`；手动检查页面初次进入、刷新直达、返回导航、无权限角色和窄屏显示。新增或修改路由、接口时同步更新路由说明或 `API_DOCUMENTATION.md`；新增子项目时单独记录依赖、启动和打包命令。

## 启动与打包

### 主项目（仓库根目录）

```powershell
npm install
npm run dev
npm run build
npm run preview
```

`npm run dev` 启动 Vite 开发服务器；`npm run build`（或 `npm run build:prod`）生成生产包到根目录 `dist/`；`npm run preview` 本地预览构建结果。`npm run build:example` 使用 `example` 模式。

### AI 答疑子项目

```powershell
cd src/dayi-fronted
npm install
npm run dev
npm run build
npm run preview
```

子项目开发服务器端口为 `8049`，`/api` 代理到 `http://localhost:5000`；构建产物在 `src/dayi-fronted/dist/`。主项目 API 地址通过 `.env.development`、`.env.production` 的 `VITE_API_BASE_URL` 配置，超时项为 `VITE_API_TIMEOUT`。可参考 `.env.example` 配置本地环境，环境文件中的地址按实际后端环境设置。

两套前端都需要各自的后端 API 服务配合。主项目路由使用 HTML5 history，部署时 Web 服务器需将前端页面路由回退到 `index.html`。根 `npm run lint` 带有 ESLint 自动修复参数，会改写文件；执行前先确认工作区状态。

### 后端与环境接入

本仓库包含前端，没有后端服务代码或后端启动脚本。主项目 `src/api/index.js` 从 `VITE_API_BASE_URL` 读取 API 地址（未设置时使用 `/api`），并从 `VITE_API_TIMEOUT` 读取超时（默认 10000 毫秒）。根目录 `.env.development`、`.env.production` 和 `.env.example` 都定义了这两项及 `VITE_APP_TITLE`。AI 答疑子项目开发代理固定指向 `http://localhost:5000`。

## 交接时需遵守的业务约定

- 讨论区发表评论按钮的位置是待关注的界面问题，代码在 `src/components/class/modules/ClassDiscussionModule.vue`。
- 代码问答不能复制或粘贴；当前页面在 `src/views/experiment/ExperimentQuestionAnswer.vue` 已拦截复制、剪切、粘贴等操作。
- 实验分析应放在课程控制台的课程管理中。当前 `src/components/course/modules/ManagementModule.vue` 仍是占位内容，且课程管理标签在 `CourseTabs.vue` 中被注释；新增或调整该功能时从此处接入。
- 出题后应立即入库。题库页 `QuestionBankDetail.vue` 有“直接生成并入库”流程，也保留了先预览再保存的流程；维护出题功能时确认默认操作符合此约定。
- 管理员课程、班级列表和教师课程列表每页固定显示两行卡片，列数按响应式栅格自动调整；分页请求条数需同步使用自动计算出的列数乘以 2。
